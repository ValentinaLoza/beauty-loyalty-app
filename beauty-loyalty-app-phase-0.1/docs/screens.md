# Screens

## Compartidas

### Splash
Inicializa servicios, comprueba sesión y resuelve rol.

### Onboarding
Solo primera apertura. Explica tarjeta digital, beneficios y funcionamiento general.

### Login
Ingreso por email y contraseña.

### Activar cuenta
Permite a una clienta invitada vincularse con una ficha ya existente.

### Recuperar contraseña
Flujo de recuperación mediante email.

# Admin Panel

## Dashboard
Resumen de servicios, ingresos, turnos y beneficios.

Listado, búsqueda y filtros.

## Notas
